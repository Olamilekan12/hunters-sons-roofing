# Hunter & Sons Roofing

React + TypeScript + Vite website source.

## Run locally

1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open the local URL printed by Vite.

## Build

Run `npm run build`. The production build is generated in `dist/`.

The estimate form uses a `mailto:` handoff. It does not store submissions on a server.
